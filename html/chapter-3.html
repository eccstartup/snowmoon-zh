第 3 章

Meldan, Veridia·3724 Snowmoon 8

Gladias（格拉迪亚斯）沿人行道向前走着。路的两侧，一家挨着一家的小店铺，卖着从鲜花到衣物再到电子设备的各种货物。他穿过一条街。

街的另一侧，路面向下倾斜，毫无接缝地接入一条隧道；隧道里的光线刚好够人舒适地看清、阅读，但也仅此而已。

Gladias 来到一个 Y 形路口。墙上贴着一张海报，四角用四段胶带粘住。他停在海报正前方看了起来。


从一个安逸的 Veridia（维瑞迪亚），到一个强大的 Veridia

Veridia 是个美丽的国家，学校里是这样教你的。你每天都看得到：树木、群山、房屋与楼宇，全都在为再挤出几个基点的土地税减免而努力。

但你心里清楚，问题确实存在。Veridia 上一次进入太空是什么时候？二十年前。Veridia 最高的建筑是哪年建成的？四十年前。为什么？因为你所有的制度——引导会（Steering）制度、图谱资助（Graph Funding）机制，以及那种文化本身——都是围绕着让人在当下过得舒适、快乐而建立的，毫不在意明天。

与此同时，看看 Arctic Empire（北极帝国）。哪里的住房、交通、工业建得最快？在 Arctic Empire。所有致力于让人活得更久的科学家呢？在 Arctic Empire。

Veridia 对那些科学家说什么？活得更久没那么重要。死亡与出生都没什么，它们是生命的自然循环。是的，他们就是这么相信的。生命的自然循环，是他们所能拿出的最好的道德——按同样扭曲的逻辑，任何不义都可以是自然的，就像老虎吃兔子。

Veridia 对自然的图景像一株植物。美丽，却从不超出自己的身高生长。我们对自然的图景像一头狮子。如果这幅图景吸引你，如果你希望 Veridia 更强大，去伸手触及星辰，不再满足于公共卫生的微小改良，而去追寻永生，那么 Veridia 需要你——下一代领导者——来掌舵。别理会那群乌合之众。去建设未来。加入我们，我们一起把它建成。

谨启，

Lord Ephelion（埃菲里昂勋爵）

Arctic Empire 驻 Veridia 领事。


"好啊，又是 Arctic 宣传"，Gladias 想。当然，Arctic Empire 像所有人一样有言论自由，但他琢磨着，什么样的 Veridia 人才会乐意破坏公共环境，把一张打印的宣传贴到 Veridia 的隧道里。他开始盘算怎么把海报撕下来。

忽然，Gladias 感到肩膀上被轻拍了一下。

Gladias 转过头。

"哦，是你吗，Mov（莫夫）？"

"不，是 Arctic Emperor（北极皇帝）。我是来把你的灵魂生生吸走的。"

"好吧好吧……等等，正走向 Greater Plum Harbor（大梅港）、穿着匿名长袍（privacy robe）的人，连同我有上百个，你怎么找到我在哪的？"

"你一年前把我加进了你的信任名单，一直没删，所以我们各自的本地 AI 有权开启位置共享。你的 AI 知道，在我跟着你去见那位神秘绅士之前，我们先要碰个面，所以它今天对我解锁了位置共享。"

"啊啊，我懂了……什么语境亲密之类的，反正是个新流行词。"

"嗯，大概连两方混淆电路（two-party garbled circuit）那套功能都用不上。"

"那你最近在琢磨什么？"

"我这年负责互联网媒体上的一张开放度评分表（openness rubric）。我们守望者（Keeper）小组一直在讨论，要提高对限制 API 行为的税。一个月前我跟一个市民议会（citizens' assembly）聊过这个话题，他们对现状非常不满。"

"为什么现在成了这么大的问题？"

"Bluewhale（蓝鲸）一个月前宣布，他们要砍掉自己的 API，只允许经过验证的硬件接入平台。他们说这是为了防止自动化垃圾信息，但议会里几乎所有人都认为，他们只是想封杀替代性接口，好更多地操控人们的注意力、榨取更多钱。"

"我们确切知道他们在做什么吗？他们的算法有公开的吗？"

"没有，他们的算法完全不透明，而且他们为此已经在缴最高税档了。"

"我明白了……"

"所以是的，很多守望者认为我们该对这类行为加更多税。要么他们停手，要么——他们就继续做，互联网变得更糟，但政府能拿到足够的钱，让我们可以给每个人提供更好的医疗。问题是，Bluewhale 一直在大力游说反对这件事。有位守望者没注意自己的隐私，她和她的观点最近被人挖了出来，传开了，几天后她丈夫就丢了工作。不知道这两件事有没有关联，但——这就是为什么我们得用这一整套东西来运转税收系统：那些密码学网络随机抽选守望者、匿名讨论和投票，还有匿名长袍。"

提到 Bluewhale，把 Gladias 带回了年轻的时候——那时他靠为另一个主要社交平台 Silverchat（银聊）写替代客户端学会了编程。他知道，这之所以可能，只是因为 API 是开放的，平台允许开发者制作替代客户端，也允许用户导出并迁移自己的数据——这些决定无疑都出于要降低自己在硬件与软件开放度评分表上的税率，或者至少是对账房先生们这么交代的。正是那段经历，促使 Gladias 去回馈，也让他自己投身到引导会之中。

"话说回来，说到隐私，你那位 200 rep 的匿名朋友，你打算怎么办？"

"他说他认为整个引导会机制从根本上就是坏的。我想，那就听听他怎么说。就算一个人是疯子，往往也至少有百分之十的地方是有意思地对的。而且，希望能从中找出点线索，弄清楚他是怎么找到我的。"

"那……万一这是个圈套，是为了弄到更多能拿捏你的把柄呢？"

"如果他真想害我，大可以直接把我的身份和任务提交进网络，把我踢出这一整年哨卫（Sentinel）资格的候选名单。不过话说回来，弄清楚这类事情，正是你在这儿的用处。"

Mov 于是掀开自己的匿名长袍，从内侧口袋里取出一个很大的包裹。

"给，在谈正事之前，先换上一件全新的匿名长袍。万一你这件上沾了什么能被人追踪的脏东西呢。Arctics（北极人）往这里偷运监视设备的本事越来越强，比我们探测它们的本事涨得还快。我们得把疑心病再提一档。"

"照这个程度，我们干脆别当面见不就好了。"

"得了吧，Glad（格拉德），你不只是马上要跟我一起当哨卫的人，你是朋友。我喜欢我们见面的时候——趁我们还见得了的时候。"

隧道向上倾斜，室外的光又一次照进 Gladias 的眼睛。小路两侧被树木覆盖。

他经过两个站在饮水泉边聊天的孩子。他能分辨出其中一个在说最近和家人去了趟 Northglade（北谷），另一个则在说他喜欢他们的 Helisport（直升机球）队。

他走出一段、远到再也听不见他们的谈话之后不久，手表震动了。

他看了一眼。

Seila 从 Freetown（自由城）发来了一些照片。第一张是这座城市的市中心。第二张是一座大公园，是从一处入口大门前拍的。画面左侧，他能看到一张写着字的告示。他把手表凑近眼睛，辨认出一份价目表。

Gladias 按了个按钮，回了一个爱心符号。

他把注意力从手表屏幕移回街道，发现自己已经进入了 Meldan（梅尔丹）更城市化、更商业化的区域。

他的右侧是一排办公楼。远处的那些泛着通透的玻璃与钢结构的亮光，只是隔着树冠，在那个距离上只能看到一部分。近处的那些正在施工，全都围着一道道高大宽阔的挡板，把工地挡在公众视线之外。

第一道挡板上，他看到一张海报，提醒 Veridia 人善待自己的家人与社区。

第二道挡板上，他看到又一则 Hydrafill（海德菲尔）的广告。广告左侧展示着经典的 Hydrafill 水瓶，覆着黄色与绿色。

右侧则是一段文字：

氢氧化氢：

  • 一种在有毒污水中常见的物质
  • 大剂量下可致命
  • 常被施予正在受刑的囚犯
  • 以其固态形式长时间接触，会造成皮肤损伤

但你可知道，你今天就能买到一瓶属于你自己的、新鲜可饮用的氢氧化氢？

Hydrafill，即刻购买。

Gladias 又笑了。施工已经持续了很久，他对这两张遮住工地的海报都心存感激。比起塔吊和建了一半的混凝土楼，他远远更乐意看 Hydrafill 的广告或者Veridia 的美德海报。

他随后把注意力转向左侧那道长长的、城堡般的墙，灰与紫两色交杂。

墙前有两排树，中间夹着一条人行道。

树后，墙上挂着一大幅海报：

"了解 Greater Plum Harbor 正在为你的社区做什么！"

文字的背景下，画着拾垃圾的机器人，是那种适合儿童的卡通风格。右下角有一个二维码。Gladias 出于好奇扫了它。


Greater Plum Harbor 公共活动

环境
  • 清洁
  • 污染监测（水、空气）
  • 动物福利研究
健康与医疗
  • 关于食物、环境与清洁空气改善效果的大规模研究
  • 健康饮食、锻炼及其他行为与生活方式研究
教育
  • 编写面向 4-18 岁的高级教育课程
  • 青少年数学与编程竞赛
艺术
  • 美丽城市研究
  • 向公众开放的展览与博物馆
  • 电影与剧集，去年有三部进入 Veridia Top 20。
GPH 完成的所有研究成果与工具均开源！
部分由 Veridia 二次方资助（Quadratic Funding）资助

Gladias 看到两个人坐在长椅上，各自喝着茶，看着那块广告牌，其中一人膝上放着一台手边设备（hand device）。

"你进去过吗？"，第一个男人问道。

"没有，我从没弄到过签证"，第二个答道。

"那地方很迷人，里面看起来跟 Veridia 其他地方完全不一样，几乎像是一个国中之国。"

Gladias 停下脚步，面朝广告牌，以免引人起疑。偷听别人谈话略有些失礼，但了解民情是他身为未来哨卫的职责之一。市民咨询议会是有用的，但那些都比不上人们没意识到有人在听时的一场真实交谈。

第二个男人低头看着两人共用的那台手边设备。"哎哟，看看他们交的税。"

"他们交什么税？"，Gladias 问 Emerald（翡翠），声音压得极低，只有他的颈带（neck band）能辨出他在说什么。

Emerald 立刻回答。

"销售税，平均 5.2%，是全市平均的一半。土地税总计 1.48%，略高于全市平均。图谱资助、尤其是二次方资助的收入，能补回其中大约一半。"

Gladias 把注意力转回那场谈话。

"我不明白。这些人就安安静静待在一个角落里，自成一隅。我从没去过那儿，他们也从没来烦过我。他们还做那些环保、教育、医疗、他们博物馆的工作。他们甚至不能只做自己真正擅长的科学，还得做所有这些讨好大众的事，好把税压下去，从二次方资助里拿回点钱——而这些事他们根本不擅长。就算做到这个地步又怎样？还是那么多人恨他们，装模作样地说他们的墙难看，只为把他们的土地税推上去。我们这么擅长做自己最大的敌人，又何必那么操心 Arctics？"

"至少在这里，这已经是我们能对他们做的最狠的事了。要是在 Devanvil（德文维尔）或 Inglewore（英格尔沃），Greater Plum Harbor 就得拼命争取不被整个关停。"

Gladias 将近十年没进过 Greater Plum Harbor 了，这让他更想再看它一眼。他继续往前走。

Gladias 把表靠近入口大门上的绿色圆圈，等了大约一个 tick（滴答）。

"证明已验证，欢迎"，机器用既机械又赞许的语调答道。

他穿过大门。

他立刻明白了长椅上那两个人为什么说 Greater Plum Harbor 与 Veridia 其他地方如此不同。

Greater Plum Harbor 内部的建筑比外面更整齐划一，都是相似的圆形与矩形，白、灰、紫三色交杂，高度大致在五到十米之间。树木只有少数几种，沿人行道等距精心栽种。店铺和餐馆除了各有名字、各有四分之一米宽的标志之外，完全不去凸显自己，而是接受自己作为 Greater Plum Harbor 整体中一个小元素的视觉角色。这些建筑明显比 Veridia 通常的建筑更未来派、更多玻璃与钢、有更多锐利的棱角。

Gladias 照着手表上的指引继续向前走。五分钟后，他来到一处隧道入口，走了下去，短暂经过一个有许多人走动的地方。

他刚穿过人群，手表就震动了。

两个问题，Gladias 想。

第一，人太多，通风或过滤不足。Gladias 拉了拉匿名长袍前脸罩上的带子，把鼻子上下两个区域隔开。

第二，不知道那些没有证明断言的设备是什么。如今，几乎每一台设备都带有一份零知识证明（zero-knowledge proof），证实它由某个特定厂商的某个特定批次生产。五十五台里有六台没有证明断言，这个数字高得不寻常。可惜，没时间弄清楚。可能是孩子的科学项目，Gladias 想；也可能在 Greater Plum Harbor，设备没有证明断言本就再正常不过——毕竟从 Veridia 的角度看，这片地都只是一家巨型企业的私有财产；还可能是隐藏的间谍摄像头，或者更糟。他稍微加快了脚步，继续走。

在迷宫里又转了好几个弯，他又回到了室外，这一次是在一处隐蔽庭院的正中央。那里摆着几张桌椅，有人正在吃东西、喝水。Gladias 找到一张带布帘遮挡的隔间里的桌子。他走进去坐下。

桌子远端的正中摆着一盏有装饰的灯，两侧各有一朵大花。地板上，紧贴着隔间的角落，Gladias 注意到一个白色的盒子。他凑近细看，手表震了一下。PM2.5 读数低于 1。肯定是空气过滤器，他想。他摘下匿名长袍的兜帽。

他把手表轻碰桌面中央的一个绿色圆圈，片刻后听到一声确认音。

两分钟后，一个带着笑脸的机器人滑到桌旁，端着一杯水和一份沙拉。Gladias 把两样都接过来放到桌上，机器人便滑走了。

五分钟后，另一个穿着匿名长袍的男人走了进来。

"那么，我们终于见面了。"

"你找到我，说你知道些我需要听的事、却只想当面告诉我，还把我带到 GPH 一个我根本不知道存在的偏僻角落。可到现在我连你叫什么都不知道。"

"啊，我叫 Delwart（德尔瓦特）。幸会。"

"我叫 Gladias。"

"这我知道。你妻子叫 Seila，你孩子的名字是——"

"你这是在恐吓我吗？"

"其实不是。仔细想想，那更像是炫耀罢了。我道歉。"

两人沉默了几分钟。他们都摘下匿名长袍的面罩和兜帽。Gladias 开始喝他的水、吃他的沙拉。Delwart 把自己的手表轻碰桌上那个绿色圆圈，一分钟后，他自己的茶，还有某种长方形的营养棒和一把叉子，送到了。

Gladias 又向前倾了倾身。

"那你想要什么？"

"你最近对引导会这套制度满意吗？"

"它和任何制度一样有缺陷，但总体上还好吧？"

"我明白了，我还没攻破你的防线。好，那就拿 Dreadknot（死结）的演唱会举例吧。他们是个不错的乐队，很好玩，对吧？"

"是啊，我喜欢他们。"

"但有一批哨卫正想办法把他们推到第 4 级（Tier 4），因为他们的歌词不够温和。"

Gladias 点头表示同意。

"你很勇敢，投了第 3 级。大多数见习者（Acolyte）都会屈服于他们以为哨卫想要的。你没有。这很难得。"

"再举个例子。你怎么看 GPH？"

"那显然是个好地方。不像 Veridia，但自有其美丽和气派。它不适合所有人，但我能理解为什么很多人喜欢来这里。"

"那你知道他们的引导会税是多少吗？"

"引导会税还行，但他们在土地税上被压得很惨。"

"正是如此。一番深思熟虑、论证这地方对 Veridia 有多大益处的说辞，还不如一句随口而出的'我不喜欢你'值钱。"

"那你提议什么？"

"自由。真正的自由。别总想着去轻轻推每个人一把，让人们真实的自我显露出来。"

"那我能帮上什么？"

"如果两个月后你被录取，你打算当哨卫还是守望者？"

"到目前为止，想的是哨卫。"

"当守望者。然后见到评分表（rubric）就投删除票。"

"就这样？这就是你的计划？"

"你看，如今哨卫比守望者多得多。而哨卫才是所有人想影响的对象。为什么？因为哨卫和世界上具体的事直接挂钩，守望者调整的则是全局规则。但任何单条规则对任何单个企业的影响都有限，而且每一条规则都大约有二十个守望者在做决定。当哨卫，你的影响要实在得多。也更有意思。"

"我的方案不一样。我在尽力召集尽可能多的守望者，因为我想要的是系统性的改变。这不是一场演唱会、或一块紫色用得太多的飞地的事。这是要把 Veridia 人从人们偏见的暴政中解放出来，让他们做自己。"

"你也想去掉图谱资助吗？"

"我觉得图谱资助在很多方面确实也越界了，但我的重点是引导会。"

"图谱资助支持的很多开放技术，对帮助 Dzego（泽戈）现代化以自保相当关键，你不觉得这很重要吗？"

"听着，我喜欢他们的人，但我们这是在玩一个危险的游戏——离资助一场潜在的战争只差一线。我们该先关注自己的问题。"

Delwart 不再说话，开始喝自己的茶、吃自己的营养棒。Gladias 趁这个空当琢磨 Delwart 的话，一边继续喝水，一边把沙拉吃完。

"这个想法很有意思——引导会只不过是在过度操控人心。我不确定自己是否完全同意把它直接清零，尤其是砍掉图谱资助——如果引导会税归零，我们就不得不这么做。"

Gladias 停了几 tick，看着 Delwart。Delwart 也回望他。两人各自又啜了一口各自的饮品。

"但好吧，就算我可能同意其中一些，我为什么要听你的？"

"因为我了解你，我知道你住哪，我知道你怎么想。而如果我能查出这些，想想 Bluewhale、或者 Arctics，能做出什么样的事。我可以帮你保护自己。但我也需要你的帮助。"

"总之，你提交最终路线决定的截止日期大约在一个月后。别去当哨卫，当守望者。我们就从这开始。"

Delwart 站起身，走出了隔间。

Gladias 把帘子中间那道缝略微留着，看着 Delwart 离开。就在 Delwart 快要从视野中消失前，另一个穿着匿名长袍的人从隔壁隔间走出，跟上了 Delwart。

Gladias 看了看手表。
