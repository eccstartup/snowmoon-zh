# 专名体例统一（修正 pass 专用）

适用于**已经译好、但专名用了中文**的章节（第 1、3、7、10、12 章）。

## 0. 规则一句话

**专名（人名／地名／国名／民族名／语言名／机构与组织专名／品牌与产品名／棋戏名）在正文里一律写英文原词**，
仅在该专名**本章第一次出现**时补一次中文括注，写作 `Veridia（维瑞迪亚）`、`Gladias（格拉迪亚斯）`。
第二次及以后只写英文。

**不要**动机制／技术／装置／单位这类概念词——它们保持「中文（English）」不变，例如
手边设备（hand device）、算力盒（compute box）、零知识证明（zero-knowledge proof）、二次投票（quadratic voting）。

## 2. 不要改的（保持现状）

- 引导会（Order of Steering）、守望者（Keeper）、哨卫（Sentinel）、见习者（Acolyte）、传令者（Herald）、
  议会、参议院、法院、图谱资助、二次方资助、密码学抽签、二次投票、评分表（rubric）、市民议会、
  最高议会、密钥分配组、泽币、匿名长袍、防传声箔、颈带、手边设备、算力盒、光尺、滴答、长时、
  共同家庭——一律维持「中文（English）」的现有形式。
- 日期与 dateline：`3724 Snowmoon 3`、`Pafogai Du, Dzego` **逐字保留**，不要动。
- Dzegoban 造语罗马字（`dze kai lin pan`、`MU GU GEI FA`、`Dze go ba fau gie`…）**一个字母都不许改**。

## 3. 单字名的陷阱（第 10、12 章尤其注意）

`白`、`穆`、`苏`、`芬`、`登`、`敏`、`扬` 既是人名也是常用字。
**只在指人时**改：作主语／宾语／呼语，或后接 说、问、答道、点头、看向、思忖、笑 等动作词，或本身在括号里作括注（`（白）`）。
**绝不改**普通词义：白色、明白、穆然、苏醒、芬芳、登上、敬敏、扬起、扬声、飘扬。

## 4. 改写方式

- **不要重译**。除专名及其括注外，**一个字都不要动**——句子、标点、引号、段落划分全部保持原样。
- 括号形式：中文全角括号 `（）`，紧跟在英文名之后，中间不加空格。
- 括注只在本章**第一次**出现该专名时给一次；`Veridia（维瑞迪亚）` 之后再出现就只写 `Veridia`。
- 如果同一段里第一次就把几个专名一起带出，就按出现顺序各自括注一次。
- 原文里用中文写成的**造语释义引号内**（如「泽戈必将再起」）也把专名换成英文（「Dzego 必将再起」）。
